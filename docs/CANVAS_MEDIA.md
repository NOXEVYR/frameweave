# 画布素材、输入端口与继续编辑

## 导入图片和视频

把 PNG、JPG、WebP 或 MP4、WebM、MOV 拖到画布空白处，会在落点建立参考素材节点；拖到已有参考节点会替换素材。节点内“点击选素材”和右侧“选择图片 / 视频素材”也可使用。图片上限 20 MiB，视频上限 200 MiB。

预览先显示，再保存到客户端本地素材目录；不需要启动推理引擎。保存失败时节点显示错误，已有素材保留；较晚选择的文件优先，不被较早的上传覆盖。图片与视频类型不匹配已有连线时，替换会拒绝，请先调整连接。

运行时，客户端把素材传到目标引擎。视频还会检查工作流开放的视频字段和当前节点定义；目前支持 LoadVideo.file、VHS_LoadVideo.video 文件输入。素材可预览不代表任意模型都能接收视频。

画布文件保存素材引用，不内嵌原始媒体。迁移设备时需一并保留客户端数据目录中的 local-assets-media 和旧 local-assets-images。删除节点不会删除素材原文件。

## 连接与排序

按住来源节点的右侧输出端口，拖到目标的具体输入端口后松手；也可以依次点击输出和输入。文本、图片和视频端口分开。一个输入槽只接一个来源，同一来源可以连接不同槽位。

Qwen 多图编辑的第一个输入是编辑目标，后续槽位按编号排列。右侧“输入端口用途与连接”可以把名称改成“场景参考”“人物参考”等；名称仅帮助区分用途，实际语义仍取决于工作流与提示词。端口编号和名称都会保存，连线顺序不会随拖动节点改变。已有连接不适合新生成模式时，会先要求调整连线。

生成或结果节点可以连接到下游编辑工作流，运行将执行所选节点及其上游。若只想修改已经生成的图片，使用结果卡的“接入 Qwen 多图编辑”或“接入重绘”：会复制现有图片到客户端素材库并连接新的编辑节点，不重新生成原图。

## 编辑预设的内部工作流

图片、视频预设也有“进入工作流”。客户端使用当前引擎的节点定义编译预设，让 ComfyUI 的实际节点构造器建立原生图，再回编译核对参数和连接。首次进入需要有效模型及所需素材；前端没有相应导入能力、缺少扩展或转换不一致时会明确报错，原预设保留。

修改内部结构后，点击“应用参数并返回”，选择外层参数、输出，并确认旧输入的对应关系。应用成功后该节点按完整工作流包执行；返回后可继续在外层调参。保存内部草稿与应用外层配置是两个动作，单纯返回不会把未应用的修改用于生成。

## 查看生成过程

画布生成节点、右侧生成队列与独立生成页面显示当前执行节点和该采样节点的步数；支持中间图的后端还会显示预览。这不是整套工作流的总百分比，进入新节点时会重新计量。实时通道断开时明确显示回退到任务查询；不支持逐步事件的节点不会出现编造的百分比。

进度事件依据 [ComfyUI 官方通信文档](https://docs.comfy.org/development/comfyui-server/comms_messages)。预览是中间结果，最终保存产物仍以任务历史返回为准。
