## 当前参考视频的尺寸与时长

内部受控参考预览显示当前浏览器读取的视频尺寸和有限时长。元数据尚未加载、尺寸未知、时长未知和加载失败分别说明；换素材、清除或关闭重开不会沿用上一份信息。显示只描述当前预览来源，不代表 VHS 节点裁剪／跳帧／缩放后的结果，不推断帧率或音轨，也不会修改原输入。

隐藏预览所属页面会暂停音视频，恢复可见后由你手动播放。设置中的“客户端素材与登记额度”只在打开或手动刷新时读取：显示客户端副本文件字节和输入登记数，不包括模型与后端文件，也不自动删除素材。暂不可读表示无法核实，不等于占用为零。

# 画布素材、输入端口与继续编辑

## 导入图片和视频

把 PNG、JPG、WebP 或 MP4、WebM、MOV 拖到画布空白处，会在落点建立参考素材节点；拖到已有参考节点会替换素材。节点内“点击选素材”和右侧“选择图片 / 视频素材”也可使用。图片上限 20 MiB，视频上限 200 MiB。

预览先显示，再保存到客户端本地素材目录；不需要启动推理引擎。保存失败时节点显示错误，已有素材保留；较晚选择的文件优先，不被较早的上传覆盖。图片与视频类型不匹配已有连线时，替换会拒绝，请先调整连接。

运行时，客户端把素材传到目标引擎。视频还会检查工作流开放的视频字段和当前节点定义；目前支持 LoadVideo.file、VHS_LoadVideo.video 文件输入。素材可预览不代表任意模型都能接收视频。

画布文件保存素材引用，不内嵌原始媒体。迁移设备时需一并保留客户端数据目录中的 local-assets-media 和旧 local-assets-images。删除节点不会删除素材原文件。

## 连接与排序

按住来源节点的右侧输出端口，拖到目标的具体输入端口后松手；也可以依次点击输出和输入。文本、图片和视频端口分开。一个输入槽只接一个来源，同一来源可以连接不同槽位。

Qwen 多图编辑的第一个输入是编辑目标，后续槽位按编号排列。右侧“输入端口用途与连接”可以把名称改成“场景参考”“人物参考”等；名称仅帮助区分用途，实际语义仍取决于工作流与提示词。端口编号和名称都会保存，连线顺序不会随拖动节点改变。已有连接不适合新生成模式时，会先要求调整连线。

生成或结果节点可以连接到下游编辑工作流，运行将执行所选节点及其上游。若只想修改已经生成的图片，使用结果卡的“接入 Qwen 多图编辑”或“接入重绘”：会将现有图片上传到当前推理引擎的输入目录，并连接新的编辑节点，不重新生成原图。图片复用依赖该引擎上的输入文件，不能只复制客户端目录就认定迁移完成。

结果卡的“传入工作流”可以选择具体分支和批次，再选择现有工作流的命名输入；场景参考、人物参考和动作视频分别连接。建立参考后尚未生成，需要显式运行目标工作流。内部控件可临时显示外层连线素材，保存与导出仍保留内部备用值，避免断开连线后丢失原配置。

Phase8N候选按后端媒体角色区分结果：input是加载器回显的原素材，不显示为生成产物；output和temp生成预览继续保留。旧任务恢复遵循同一规则，不删除原素材文件。成品与验证范围见[Phase8N发行说明](../releases/PrismCanvas-0.11.5-Phase8N.md)。

## 编辑预设的内部工作流

图片、视频预设也有“进入工作流”。客户端使用当前引擎的节点定义编译预设，让 ComfyUI 的实际节点构造器建立原生图，再回编译核对参数和连接。首次进入需要有效模型及所需素材；前端没有相应导入能力、缺少扩展或转换不一致时会明确报错，原预设保留。

修改内部结构后，点击“应用参数并返回”，选择外层参数、输出，并确认旧输入的对应关系。应用成功后该节点按完整工作流包执行；返回后可继续在外层调参。保存内部草稿与应用外层配置是两个动作，单纯返回不会把未应用的修改用于生成。

## 查看生成过程

画布生成节点、右侧生成队列与独立生成页面显示当前执行节点和该采样节点的步数；支持中间图的后端还会显示预览。这不是整套工作流的总百分比，进入新节点时会重新计量。实时通道断开时明确显示回退到任务查询；不支持逐步事件的节点不会出现编造的百分比。

0.11.5 候选在断线和重新连接但尚未收到新事件时，将缓存明确标为“上次进度 / 预览”；新事件到达才恢复实时标记。客户端服务本身断开时显示正在重连和耗时暂停同步。独立工作台也显示耗时：排队中计排队时间，有开始执行时间的任务计执行时间，旧记录没有开始时间时从创建起累计。中间预览不是最终产物，也不保证每个视频或音频节点都提供。

进度事件依据 [ComfyUI 官方通信文档](https://docs.comfy.org/development/comfyui-server/comms_messages)。预览是中间结果，最终保存产物仍以任务历史返回为准。

## 画布管理与节点下方调参（云端候选，2026-10-13）

点导航中的“画布”先进入管理页。输入名称并新建空画布，或从已有保存版本中打开；“继续编辑当前草稿”保留尚未另存的编辑。返回管理页不会另建画布。保存创建一个新命名版本，浏览器自动草稿仍单独保留。切换有未保存更改时，可以保存后继续、明确放弃更改，或取消；保存失败保持当前编辑并显示错误。重新加载的旧草稿不被假定为已核实的命名版本。

选中一个节点，在其下方直接编辑同一组参数；面板按屏幕保持可读大小，随画布移动调整位置。用“停靠到侧栏”继续在原属性区域编辑。多选、返回管理页或节点替换时，旧参数控件不再拥有写入权。输入法合成期间请先完成输入再切换或退出。模型候选、工作流字段、素材和可运行性仍以当前后端定义为准；此面板不证明已安装模型或已完成生成。

## 桌面返回与退出（Windows 原生验收待补）

再次启动棱光时优先找回已核实的实例，旧窗口找不到则重新打开主界面。Windows 托盘就绪时提供“打开主界面”“设置”“退出棱光”，关闭浏览器页面后默认保留后台；设置可选无活动且任务安全时约 180 秒后退出。此设置不接管系统浏览器关闭按钮，也不会自动隐藏唯一页面。托盘不可用时，界面明确提示，并使用受任务保护的空闲退出行为。Linux 不宣称 Windows 托盘可用。

“退出棱光”在服务停止前检查活动任务、待确认提交、编辑器、素材状态和浏览器草稿。失败时保留服务和页面，提示先处理任务或保存/导出；确认回包丢失时不要假定已退出，也不会自动重试。Linux 的协议与界面检查不能替代 Windows Shell、DPI、菜单和实际窗口行为验收。
