# 一个应用管理本地创作环境

棱光 0.9 在「设置」中提供引擎中心。已经安装的 ComfyUI 只需登记一次；程序识别安装目录下的 venv / .venv，或便携版相邻 python_embeded。模型和工作流保持原文件，棱光不再为每个模型建立客户端副本。

「连接」切换当前后端；「后台启动」先识别已有服务，在线时直接复用。非 ComfyUI 服务占用了端口时拒绝启动。自动启动为可选设置，只启动当前登记的引擎。棱光不终止外部推理进程，退出客户端也不会关掉其他软件的任务。

工作流包库可同时保存原版模型、不同编码器和量化模型的工作流。它们可以作为节点加入同一画布；选择工作流与启动客户端是两件独立的事。原生 Qwen 2.1 与 GGUF 工作流仍有不同的节点依赖，环境中心按实际可用节点检查。

每个用户数据目录仅运行一个服务。桌面快捷方式建议使用 `--open-existing`：已有窗口优先聚焦，窗口关闭而服务尚在时重新打开。仍在运行的 0.8 客户端会被保留，升级不强制关闭旧会话。

## 更新

设置中可手动检查、下载校验、安装并重启。自动更新默认关闭；开启并保存后立即检查并下载，后续启动同样自动检查，在任务空闲退出时安装。浏览器窗口关闭后有短暂宽限期；最小化不会触发更新退出。生成中、工作流调度中或提交结果未确认时，退出安装会被阻止。

更新来源固定为 `NOXEVYR/frameweave` 的公开发行目录。包先验证 HTTPS 来源、字节数、SHA-256、ZIP 路径与解压限制，再验证唯一的 PrismCanvas.exe。超过 50 MiB 的包不自动下载。当前 Windows 安装器将新程序放入独立版本目录，保留旧版本，使用相同数据目录和端口重启，并检查新服务版本。快捷方式只更新原来指向旧程序的条目；不搬动模型与项目。

源码模式支持检查和暂存，安装切换仅适用于 Windows 打包客户端。未签名程序的信任依赖固定的 HTTPS 发布源与校验清单；散列校验不能替代操作系统代码签名。

运行日志、引擎命令配置、更新事务及快捷方式备份保存在本机数据目录，不包含在公开源码或发行包中。

## 0.9.2 的恢复行为

引擎监督由独立后台循环执行，打开或刷新设置页面不会启动、重启或终止进程。引擎一旦就绪，短暂探测失败只显示状态下降；启动等待超时也保留进程供排查。自动重试只针对尚未就绪便退出的自有进程，每次重试先检查端口。

失败更新可再次尝试同一版本：已有候选 EXE 必须重新通过大小与 SHA-256 校验才可复用，已有文件不被覆盖。候选进程已经退出且端口空闲时恢复旧版；候选仍在运行而身份无法确认时停止自动切换，保留程序和诊断信息，不强制终止该服务。此情形不属于已完成自动回退。
