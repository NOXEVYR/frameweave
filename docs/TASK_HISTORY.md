# 任务历史与参数复用

0.3.0 在原有本地任务队列上增加搜索、状态筛选、复用参数与再次生成。任务记录来自当前客户端；其他软件提交的任务不会进入此列表。

## 从历史结果继续创作

1. 打开右侧“任务”，按进行中、已完成、失败或已取消筛选。
2. 搜索匹配任务标题、ID、类型、工作流包名称及错误信息，不扫描私人提示词或模型文件内容。
3. 点击“复用参数”，在画布添加一个独立生成节点。原节点与结果不被替换。
4. 新任务保存的提示词、选定模型、种子、尺寸和参考图角色会恢复。工作流包使用原包及参数；较早任务或包已不可用时，回退为完整 API 工作流。
5. 修改参数后，手动“开始生成”。恢复参数本身不提交推理。

参考图保留的是原后端素材名称，不复制图像文件。更换后端或删除原输入文件后，需要重新上传素材。归档包仍可恢复和运行；导入原始包文件可恢复相同包 ID 的关联。

## 再次生成与重复提交保护

“再次生成”仅对已结束任务提供，并要求当前后端地址与原任务一致。它提交保存的精确 API 图，不重新猜模型或重新应用当前默认值；种子保持不变。再次生成可能命中 ComfyUI 缓存，缓存返回时间不是模型推理速度。

提交前强制读取当前节点定义，校验缺失节点、模型选项和参考图。后端地址相同不保证模型文件内容、插件或算法版本未变，因此也不承诺逐像素一致的输出。

浏览器保留每次操作的请求 ID；后端持久记录该 ID 对应的任务。相同请求或活动重试的重复点击返回已有任务。若连接中断导致无法确定后端是否接受，则停止从这条记录重提，先在原后端检查队列。核实后可通过“复用参数”创建新任务。不会自动循环重试，也不会调用全局中断影响其他软件。

后端已返回任务 ID 后，即使本地磁盘写入失败，也会显示已接受任务与保存警告。保留任务 ID 并处理空间或权限问题，避免重复消耗计算。

## 保存、容量与兼容

- 精确 API 图及规范化输入存于用户目录的 `runs/`；画布在浏览器站点存储中。公开源码与下载包不含这些记录。
- 单次新任务的复现记录上限 4 MiB，API 图不重复存两份；提交前检查。媒体仍由后端保存，客户端不缓存整段视频。
- 列表和重启恢复最多保留最近 200 条任务；历史 `runs/` 文件当前不会自动回收，总目录不是固定容量。每条源任务最多记录 64 个重试请求，达到限制后从新任务继续。
- 旧任务包含超出浏览器整数精度的种子时，不开放有损编辑；可通过后端“再次生成”保留其精确整数。
- 不同服务端口对应不同浏览器存储。升级前可导出画布和工作流包作为备份，不要把客户端目录与模型目录合并。

## 媒体与编辑状态

任务轮询只更新变化的状态和输出，未变化的媒体元素保持原实例。关闭按钮、Esc、点击预览外部或切换预览，会暂停并释放原音视频源；页面隐藏和退出也会暂停播放。恢复显示后需要手动重新打开预览。

文本输入即时进入画布状态，一次聚焦中的输入合并为一条撤销记录。数字输入未完成或暂不合法时不会写入有效生成参数。若浏览器存储写入失败会提示，应导出画布保留当前编辑。
