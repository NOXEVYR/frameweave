# 验证记录

## 0.5.0 · 2026-09-24（棱光本地版）

已验证：189 项 Python、25 项 Node、Python 编译、JavaScript 语法和兼容 CRLF 的差异格式检查。源码页面共 48 项：五宽度品牌/布局 15、原交互回归 17、AI/外部任务交互 7、竖图与边界布局 4、MCP 联动 5。最后文案与对比度调整后重跑 15 项布局。EXE 页面另通过 17 项交互和 5 项 MCP 联动；JS 错误为零。数据工作流导入、单次提交、结果入画布、撤销/重载和已有 MP4 的播放/关闭清理均经过实际页面操作。

图标校验：同图源 SVG、512 PNG、16/20/24/32/40/48/64/128/256 九帧 ICO；Windows 资源 API 只读提取 EXE，九帧与正式 ICO 逐字节匹配。EXE 为 9,558,578 字节（约 9.12 MiB），较 0.4.0 增加 37,183 字节，无新运行依赖。页面用独立系统 Edge 上下文检查；包内 UI 验收仅拦截环境扫描请求，任务与 MCP 请求仍经真实 EXE 及隔离 mock，未扫描个人推理安装。静态前端及图标随包交付，公开截图使用隔离测试后端。

边界：本轮未做新的真实 GPU 推理、外部 AI 产品配置或 Windows 原生窗口/任务栏实机验收，不据此宣称画质、算法速度或任务栏缓存已改变。最终 ZIP 的 CRC、SHA-256、源文件清单及独立解压启动结果另存交付验证记录；旧 0.3.0、0.4.0 包保留。

## 0.4.0 · 2026-09-24（本地版）

本轮完成工作台美化与本地 MCP 接口，没有改动生成算法或模型。189 项 Python 测试、25 项 Node 测试、Python 编译和 JavaScript 语法检查通过；其中新增 40 项 MCP 工具测试和 11 项实际 HTTP 传输测试。

MCP 验证包括初始化与工具发现、严格输入校验、8 种原生图片/视频请求编译、无副作用包导入、参考图上传、任务查询与取消、同键异参拒绝、跨实例锁、重启与并发去重、网络响应不确定、落盘失败、UTF-8/Host/Origin/Bearer 与协议头验证。使用模拟推理服务，不据此推断显卡性能或模型画质。

源码和 Windows EXE 各通过 17 项原有界面回归与 5 项 MCP 联动检查；源码另通过 7 项新增交互和 4 项布局回归。已检查 1024/1280/1600 宽度的主操作入口、画布与面板；AI 配置可以复制且关闭后从 DOM 清除，不进入画布导出或本地存储。MCP 创建的任务只提交一次，结果进入同一队列，可放入/定位画布，并实际播放已有 MP4。所有上述浏览器检查的 JS 错误为零。

竖图异步加载和多输出结果不再因初始高度估计不足而重叠；合法坐标边界的双参考图参数复用可保存重载。沿用旧版草稿、包库归档、重试、筛选、媒体 DOM 保留、关闭/Esc/预览切换/真实导航清理检查。页面隐藏另记为模拟事件；没有把离屏浏览器测试称为原生窗口遮挡验收。

EXE 为 9,521,395 字节，约 9.08 MiB。归档及对应源码清单用 SHA-256 和 ZIP CRC 核对；从新 ZIP 独立解压启动，验证版本、无后端时发现 14 个工具、空任务列表与内嵌前端一致性。旧 0.3.0 Windows ZIP 保持原摘要。

本轮没有重新执行真实 GPU 推理；相关历史证据在下文。第三方 AI 产品的实际 MCP 配置未分别验收，接口没有自动写入用户的 AI 客户端设置。本轮成品未发布 GitHub。界面截图展示示例画布，不能作为生成已成功的证明。

## 0.3.0 · 2026-09-18

本轮重点是任务复现、队列与包库操作、输入保存和媒体生命周期。生成算法、模型与采样器实现仍由外部 ComfyUI 提供。

### 服务与真实生成

最终 138 项 Python 测试、21 项 Node 测试、Python 编译与 JavaScript 语法检查通过。源码服务与 Windows EXE 各通过同一套 17 项实际界面检查，控制台错误为零：数字输入回退、未失焦草稿、包库整理、重启保留、归档包生成、独立参数复用、重试去重、搜索筛选、轮询保留媒体元素、播放后关闭/Esc/切换预览与真实导航退出。后端为回环模拟服务，视频素材是已生成的本地 MP4，未把这些 UI 检查冒充 GPU 生成。

页面隐藏的 visibilitychange 分支另做 1 项模拟事件覆盖；离屏 Edge 不能验证真实窗口遮挡状态，因此不把它计入真实 UI 检查。1280 宽包库与队列截图已检查，控件无横向溢出。Windows EXE 另恢复本轮真实图片/视频的 4 条历史任务并加载实际图片，首页截图来自该实例。

新增检查覆盖包整理信息持久化、导出不泄露本机整理状态、归档后仍可运行、并发部分更新；覆盖旧任务恢复、精确 API 重试、持久请求 ID、并发去重、后端改变、缺失参考图、超大记录、整数精度、磁盘写入故障和响应丢失。静态/模拟检查不代表 GPU 推理速度。

在已有 ComfyUI 0.30.0、RTX 5070 Ti 16 GB 上，确认队列空闲后顺序提交两项新任务，无新增模型下载：

| 路径 | 参数 | 本轮结果 |
| --- | --- | --- |
| Krea 图片 | 512×512，8 步，CFG 1，固定新种子 | PNG，约 14.25 秒 |
| H3 文生视频 | 768×448，20 步，124 帧，24 fps | H.264 + AAC MP4，5.167 秒，约 143.98 秒 |

两项任务均验证：保存并读取参数、再次生成的 API 图与原图完全相同、同一个请求 ID 返回同一新任务。相同图的再次生成命中引擎缓存（约 0.01–0.03 秒），只证明复现与去重链路，不计入推理性能。输出视频通过 FFmpeg 完整解码；图片和视频抽帧可见靛蓝茶壶、木桌与窗光，不据此宣称普遍画质或主观音质改善。

### 本轮保留的范围

未新增跨显卡/跨平台、长片或 Turbo 质量验证；H3 首尾帧与 Ref2VA、Krea 多图编辑等专项边界沿用下方历史记录。本轮未改动原有推理服务、模型或用户项目。UI 自动化使用独立浏览器上下文，不读取个人浏览器资料；真实页面交互与模拟可见性事件分别记录。

## 实际生成

验证设备：Windows x64、NVIDIA RTX 5070 Ti 16 GB；已有 ComfyUI 0.30.0 / PyTorch 2.10.0+cu130。本次没有新增模型下载。

| 路径 | 参数 | 实际结果 |
| --- | --- | --- |
| Krea 2 文生图 | 512×512，8步，CFG1，euler_ancestral / sgm_uniform，seed 314159 | 通过客户端 `/api/jobs` 提交并回传 PNG，约14.4秒；图片内容与茶壶、木桌、窗光提示相符 |
| MiniMax H3 文生视频 | 768×448，20步，CFG1，124帧，seed 314159；pruned INT8 + NVFP4编码器 | 通过客户端提交并回传MP4，约119.1秒；H.264、24fps、124帧、5.167秒；AAC、32kHz双声道 |

H3 完整文件经 FFmpeg 无错误解码，抽取画面确认有可辨识的茶壶、桌面和光线。音轨结构通过检查；未进行主观音质评分或音画同步评分。

耗时是本客户端观测到的单次任务时间，含模型调度/加载影响和约两秒轮询误差。两种模型的题材、尺寸和参数不同，不能作为模型间速度排名，也不构成对其他机器的承诺。

Krea 发布默认按官方当前模板使用8步、CFG1、euler/simple；本次实测额外覆盖 euler_ancestral/sgm_uniform 组合。默认组合和复杂参考编辑不能仅由这一次图像生成判定质量。
