# 统一工作流接口规范

## 目标与边界

一个工作流对应一个可复用画布节点。原生 ComfyUI 文档、API 图和工作流包进入同一套接口识别与管理规则；不按工作流名称写专属适配器。原生文档必须由实际 ComfyUI 前端及其扩展编译，不能猜测 widgets_values 的位置。导入、编译接口和运行是三个独立动作，前两者不会生成内容。

## 编译过程

1. 保留完整原文及内部草稿。
2. 用当前后端的节点 schema、编译后的图、节点标题识别候选字段及保存媒体的输出节点。
3. 自动选择参考素材、提示词、模型/编码器、常用采样/尺寸参数。其他候选保留在“管理外部接口”中，不把所有字段塞入节点。
4. 用户可修改接口名称，选择哪些字段在侧栏出现，以及可连接的文本/素材是否显示为画布端口。数值、模型选择器等作为侧栏控件。
5. 生成接口预览和运行准备状态。缺模型、未上传素材等运行问题不能阻止建立可编辑的外部面板；开始生成时仍须按最新 schema 严格检查。
6. 对内外同时修改的值、失效绑定、输出分支变化显示差异，确认重绑或解除后原子应用。取消不得半更新画布。

## 数据合同与兼容

- 沿用 `frameweave-workflow` v1，字段 `id/node_id/input/type` 保留；新增可选 `presentation: port|control`、`role`、`group`。没有这些字段的历史包仍可加载，已有连线不会因折叠或显示策略而消失。
- `id` 是保存的外部绑定标识，名称可改；既有节点/输入不变时保留 ID。内部节点被替换时必须通过显式重绑映射迁移旧连线，不能按名称、位置或“第几张”静默猜测。
- 字段类型来自 schema 和受支持的媒体上传协议。文件名字符串不是通用图片张量端口，保存图片/视频的输出也不是任意内部张量。
- 输出连接记录实际输出节点和批次序号；多个兼容输出时要求选择来源，禁止默选不同语义的第一项。
- 候选和明确外露的字段各上限 4096；默认推荐 64 项是呈现选择，不是存储截断。全部媒体必须保留，媒体超过默认预算时也不能丢弃；已有明确选择完整保留。候选、侧栏和未连接端口按 64 项分页，搜索和批量选择针对完整筛选结果。已连接端口始终保留可见锚点。
- 输入容量与其他预算独立：输出选择仍最多 64 项、API 图最多 1000 节点、包与完整接口检查结果仍受 2 MiB 限制。包含默认值和选项的检查结果超限须明确报告，不能截掉字段伪装成检查成功。
- 首版自动模式只负责有依据的识别。缺前端扩展、特殊脚本控件、未知输出协议保留原文并说明阻塞点，不宣称可以无损编译任意第三方工作流。

## 编辑会话与输入来源（候选实现）

进入工作流用于查看和修改完整结构，不应先运行上游、上传素材或裁剪到所选输出。编辑准备保留完整源图、未知节点及未连接分支；实时 schema 只能证明哪些现有输入可以临时显示，不能把“可以编辑”误报为“可以生成”。

同一接口区分三个来源：节点自身备用值、已保存的内部草稿值、当前连线输入。连线输入仅在编辑会话中临时显示；保存草稿、返回、切换引擎、导出及应用前，先恢复内部值并取得匹配的原生文档与执行图。内部对连线输入有新修改时，明确选择保存修改或保留进入前的值；连线仍继续控制外层生成，不自动修改源节点。

临时显示仅应用于能够用新编译结果证明的具名控件。未证明的子图、媒体控件保留原值并说明原因；不能按旧 widget 序号写入。来源节点、连线、素材事务、画布或后端在等待期间变化，停止旧候选保存。保存已成功但显示恢复失败，与保存结果未知分别报告，后者不会自动重复提交。

当前实现覆盖可证明的顶层标量，并新增下述标准媒体会话候选；未映射子图、特殊插件媒体仍在完善。这些限制不改变外层执行时已有的媒体归属检查与连接规则。候选源码须经过真实前端往返验收后才能视为交付完成。

## 内置预设进入工作流（候选实现）

H3 三种模式、SDXL 文生图/图生图、Krea 和 Qwen Image 2.1 两种模式共用原生成构图逻辑。进入编辑只采集节点自身参数和明确的槽位意图，不上传素材、不运行上游。缺模型或图片时保留空值及待补项；缺少构图所需的节点声明时保留完整请求并说明阻断位置，不静默切换模式或删除分支。

首次转换用实际节点/输入/类型建立可验证映射，保留多图序号空洞、首尾帧角色、已有端口用途和文本贡献顺序。ComfyUI 完成回编译核对、保存内部草稿后，外层一次性建立完整参数与接口，随后统一按工作流包处理。转换、来源检查或连接迁移失败，原画布节点和连线保持不变；已保存的内部草稿与外层绑定失败分别报告。

完全为空的静态模型枚举仍保留为选择控件及原值，并标记待补资源；不能生成虚假候选或擅自选中第一个模型。导入、保存和编辑可继续，生成时仍根据最新声明检查活动字段；无关输出分支中的空枚举不能阻断已就绪的输出。补齐资源后，在“管理外部接口”重新编译候选并明确选择。动态分支、多选、强制连线等控件不能套用此例外。

上述空枚举编辑能力和预设绑定已通过源码与临时 HTTP 回归；新后端的真实原生前端往返仍待验收。老客户端可能拒绝含空候选的包，应使用支持该合同的版本，不能依靠改变字段类型绕过。

## 文本连接与拼接

文本输入可以选择连线替换、按段落拼接或按逗号拼接。普通输入默认仍由一条连线替换；选择拼接后可以连接多个来源，按保存的连线顺序加入非空文本，最后追加节点自身文本。自身文本保持可编辑，断线后继续使用；输入面板显示全部来源，可断开全部或在画布删除单条连接。

内置预设首次迁移时，正向提示词使用段落拼接，负向提示词使用逗号拼接，保留既有贡献顺序。同一来源的正负文本分别映射到真实字段；一个参数对应多个内部输入时显式展开，不能通过重复字段 ID 或猜测同名输入代替。

旧画布有意重复贡献同一文本时，迁移通过 `sourceOccurrence` 保留各次引用和原连线 ID，缺省为第一次；相同来源、来源字段、目标字段和引用序号构成贡献身份。拼接、规划、配置及内部显示使用同一顺序，不能去重。普通拖线继续拒绝误重复；该元数据只适用于有明确拼接规则的文本接口，不能用于媒体或普通替换输入。含引用序号的画布同样使用 v2，断线不自动重编号。

保存的自身值不包含动态连线文本；执行、规划和内部临时显示使用同一合并规则。明确保存为可复用配置时才记录当次有效文本。普通画布/运行记录继续使用 v1；含拼接语义的画布/运行记录分别使用 `frameweave.canvas.v2` / `frameweave.workflow-run.v2`，防止旧客户端丢掉规则后执行为其他内容。

## 节点呈现

包库列表与完整工作流分开加载。摘要只负责名称、归档状态和接口数量；已保存画布保留自己的稳定接口，刷新列表不会重置参数或断开连线。编辑、连接和导出需要完整定义，加载失败可以重试并保留原节点。执行先确认活动依赖，再读取相应工作流；未参与本次输出的分支不因为缺包而触发全库读取。归档只影响包库分类，既有引用继续按内容 ID 读取。

节点仅展示紧凑的带名称和类型颜色的接口，不再用全宽彩色大条重复参数表。默认显示常用及已连接端口，其余可展开；所有已连接端口必须可定位。模型、编码器、种子、采样器等集中在侧栏。接口管理与内部编辑入口始终可见。拖线时多输出分支必须明确，连接到场景参考和人物参考等独立字段不能混为一个入口。

## 验收矩阵

顶部“导入画布”自动识别普通画布与包含工作流完整定义的集合，共用 24 MiB、64 层、500000 数据项边界。读取及后续校验期间，画布身份、节点内容、标题、视角或后端变化都应停止旧导入，保留当前内容；导入不触发生成。完整集合中已经写入的有效定义保留在包库，不在错误恢复时删除。

覆盖文生图、多图编辑、视频参考、大型多分支、音频、未知插件等工作流；检查原文保留、自动接口、手动外露、内部改动重编译、重命名/增删字段、连线与值保留、缺环境时可编辑、运行前拦截、刷新与导出重载。协议/合成测试、真实后端导入、实际浏览器操作、真实 GPU 生成分别记录，任何单层通过都不代表全部完成。

## 标准媒体的内部同步（E1 源码候选）

媒体文件名与预览加载分开核对。外层自身素材和已连接素材分别取得当前后端 schema 证明；连线来源不能充当自身备用素材的上传证明。原生编辑器再次核实注册节点、实际唯一控件、标准单文件上传协议和预览隔离能力，返回仅限当前图、节点和控件对象的短期回执。

只有对应回执记录的内部原值、当前连线值和最近明确观察到的内部修改值可以恢复。清理到原值再保存，不会抹掉待恢复的内部修改。新上传素材可以不在旧下拉候选中，但此例外不适用于模型、普通枚举、多选或自定义 URL/路径传输。每次编译核对回执；即使值没有变化、无需回写，也不能绕过节点被替换的检查。

保存前仍以完整编译结果和匹配快照验证。同步尚未成功时阻止应用覆盖外层新值；保存结果未知时不重发。选择保存内部新素材并应用到外层，会丢弃旧文件的归属和缩略图，不能把相同文件名当作同一引擎上传证明。回执不导出、不写入画布。

受控面板显示明确选中的一个素材槽，通过同源输入文件读取显示图片、视频或音频，不自动播放或转码；迟到加载事件被隔离。未得到回执的原生自身素材仍可查看；无法证明隔离的节点保留其原显示。节点移入子图恢复原展示；同对象重加根图产生新回执，不能继续使用旧授权。当前源码候选仅启用官方 LoadImage、LoadImageMask、LoadAudio、LoadVideo 的标准单素材控件。VHS、未知插件、多槽自定义节点、尚未上传或跨引擎媒体、未经显式传入的上游结果不在本阶段内部显示范围，保留原图并报告待处理，不代表外层媒体连线被删除。

编辑代理明确声明新协议后才加载媒体模块；旧代理保持原编辑能力并立即说明媒体尚未同步。新源码的桥接、存储及路由回归通过；真正 Canvas/Vue 展示、音视频解码和新后端的完整往返仍需单独验收。

## 已完成产物继续编辑（E2）

结果节点或右侧结果属性中点击「传入工作流」，选择产物的输出分支/批次，再选择目标工作流的命名输入。输入 ID 用来区分重名控件，搜索针对完整候选。成功后生成独立参考节点并连接到所选输入，自身备用值保持，后续运行不依赖原生成任务。直接从生成节点连接的动态执行链仍使用每次新运行的上游产物；打开内部编辑器不会偷偷运行上游。

只接受此客户端登记的已完成任务，使用稳定 output_id 校验，不能用列表序号或相同文件名替代身份。复用同一后端的既有传输接口；图片可传入预设和工作流包，视频/音频须连接有实际媒体上传协议的工作流包。传输期间换图、换引擎、删除/替换节点、重绑输入或关闭窗口时，旧响应不修改画布；选中的产物消失时要求重选，不自动选择第一项。传输失败可检查后手动重试，不自动重复传输或生成。

图片结果的「接入 Qwen 多图编辑」「接入重绘」复用同一传递事务，只是创建新的编辑目标。成功后参考节点、目标节点和 image_1 连线一次加入画布，失败不留下半成品节点；支持整步撤销和重做。新目标不能在传递途中被当前画布的同 ID 节点接管。

视频已做真实传递、预览、撤销/重做、刷新和本机保存验收。图片快捷编辑及音频命名输入也通过实际界面和文件一致性验收；两份合成测试产物只证明传递、连接及解码，不证明模型画质、听感或后续编辑生成。新 E1 内部媒体预览继续单独验收。

## 子图实例标量同步（E3 源码候选）

启用实例映射能力时，已连接的子图文本、数值等标量按完整执行路径定位实际控件。未共享的叶控件、或提升到独立实例的控件通过核验后可显示外层连线值。共享但未提升的定义不能代表某个实例，保留原值并说明需要提升输入。

桥接为当前 root、每层 host/scope、slot/link、widget/widgetId、schema 与生命周期建立会话回执。后续观察、回写、保存和恢复均重新核对；即使值相等、不需要 patch，也不能跳过身份检查。内部结构变化使回执失效，不按相同 ID 或文件名自动绑定到新对象。原生回调若改变未请求的参数或兄弟实例，整次回写失败并尝试恢复。

保存仍区分内部原值、外层自身值、连线展示值和用户内部改动。回执不会写入工作流或画布；旧桥没有此能力时明确保持原内部显示。此范围只启用连线标量，不意味着所有未连线控件都有持续回执，也不意味着子图媒体的 Canvas/Vue/提升预览已可同步；子图媒体需要下面独立的预览合同。

### 同一子图的多个实例如何分别调参

在「管理外部接口」中，按完整节点路径区分实例，例如 `4:2` 与 `5:2`；可分别命名为「场景倍率」「人物倍率」。两路媒体也分别命名和连接，输出分支分别勾选。不要把外层名称相同视为同一个内部输入。

如果提示「公共定义被多个实例使用，需先提升为实例参数」，说明该控件仍存在共享定义里，无法只改一个实例。保留外层值，进入 ComfyUI 子图，将该控件提升到子图输入，保存内部草稿后重新进入。独立实例控件建立后，客户端重新核对并同步外层值；核对通过才能「应用参数并返回」。提示未消失时，可以放弃本次未保存的内部修改并返回，外层覆盖值仍保留。

此操作已用实际 ComfyUI 前端验证：两实例独立修改、内部和外层往返、刷新、全新导入、公共参数拒绝及提升后恢复均通过。两张不同图片的外层连线也完成实际 CPU 处理，并按输出节点核对像素。结果列表顺序不构成分支身份；连接和复用应选择具体输出。共享子图提升媒体的内部预览、任意第三方控件和 GPU 模型生成仍需各自验证。


## 子图媒体与视图（E3 扩展源码候选）

不按工作流名称单独适配。标准单素材叶节点只有在真实实例路径唯一、媒体合同匹配、每层宿主的实时预览提升表均可确认且为空时，才可接收外层自身素材和临时连线素材。控件被提升到宿主、共享未提升定义、未知预览表或不支持的视图生命周期均明确保留原值。实例映射、标准媒体与子图预览三项能力分别声明，旧客户端不会误启用。

先核对并隔离预览，再捕获实例控件证明；这样同一节点的素材输入和普通参数可以共用当前实例证明。外层自身值先同步，连线值只在会话中临时显示；保存时清理连线覆盖，保存后恢复查看值。内部修改继续显式决定保存方式。短期媒体和映射回执从持久化接口、控件和未映射报告中移除。

只有当前实际子图视图里选中的节点显示独立素材面板；完整路径参与预览身份。退出子图、更换选择或节点归属变化清除旧预览，迟到的加载事件不能把原图标为新图。尚未捕获的子图媒体保留原生展示。若已显示外层素材后结构变成共享，撤销旧回执并继续隐藏可能混淆的旧预览，要求重新进入；不自动改写新的子图结构或素材值。

进入内部编辑器时，若节点都在视野外或只在边缘露出标题，自动适配当前图；已可阅读的原视角保留。顶部「适应当前工作流」随时适配当前层级，保持节点位置、参数、连线和选择不变。首次进入和按钮操作通过实际官方前端界面验收。子图媒体仍是源码合同与组合测试证据，新代理协议未加载的常驻进程不能代替真实 Canvas/Vue/编解码验收。
