# 把工作流做成填写式工具

工作流包把一套 ComfyUI API 节点和常用输入保存为小型 JSON。使用者把包添加到画布，在右侧填写提示词、尺寸、种子或参考图，就能提交整套图片或视频工作流。

包的作用是复用已经设计好的生成流程。实际推理由你连接的本地 ComfyUI 完成，所需模型、节点扩展和运行环境仍须具备。先完成一次小规模生成，再把这套配置作为日常模板。

## 在画布组合工作流（0.7.0）

每个节点代表一整套工作流，不展开 ComfyUI 内部节点。可把多套图片和视频工作流组合在同一张画布，例如：提示词 → 文生图包 → 图生图包 → H3 图生视频包。

1. 在画布“工作流集合 → 添加工作流”选择已有包；也可双击空白，选择“工作流包”。
2. 点击来源输出端口，再点击目标工作流输入端口；或在右侧输入字段点击“连接来源”。
3. 明确选择目标字段。文本输入可接提示词节点的正向或负向内容；图片输入可接参考图，或另一套工作流的第几张图片输出。
4. 连接后该字段由上游提供，表单暂时锁定；点击“断开”可恢复手动填写。尺寸、模型、LoRA 等其余参数仍在表单内调节。
5. 选择末端工作流，点击“运行所选及上游”；也可“运行整个画布”。调度按依赖顺序逐套执行，上游完成后，将该次输出图片上传为下游输入。

每个字段只接一个来源；同一来源可分给多个输入。类型不匹配和循环连接会被拒绝。只传递当前这一轮的成功图片输出，不会把历史图片或任意 URL 当作输入；视频、音频输出目前不用于跨包传递。连续运行使用开始时的参数快照，运行中修改画布用于下一轮。

运行卡显示步骤与错误。“停止后续”停止后续调度，不强制中断正在推理的任务；取消当前任务请在生成队列操作。刷新页面或网络中断后不会自动重发，点击“查询并继续”按原请求 ID 核实并恢复。上游失败会阻止下游执行；结果不确定时保留记录，不要换新 ID 盲重试。

“工作流集合 → 导出工作流集合”把画布布局、连接、实例参数和所有引用的包定义保存为一个 JSON；导入到空包库会先恢复包，再恢复连接，导入本身不提交任务。集合最大 8 MiB、最多引用 200 个包。原文传输保留包 ID；旧集合中的对象定义也兼容，并映射为本机实际导入的 ID。

集合不包含模型、扩展、推理环境、素材和输出文件。输入提示词、模型名称、固定参数及后端参考图名称仍在 JSON 中，分享前自行核对；换后端后应重新上传素材，并检查所需模型与节点。

## 整理包库（0.3.0）

搜索只匹配包名称、说明和 ID。收藏的包排在前面，也可切换“收藏”分类。归档会将包从常规列表隐藏；在“已归档”中可恢复，已有画布节点仍能找到并运行该包。没有删除或移动模型文件。

收藏、归档信息独立保存在本机 `workflow-packages/metadata.json`，不会改变包内容 ID，也不进入导出的 JSON。重新导入同一个包会保留本机整理状态。任务的参数复用与再次生成见 [任务历史指南](TASK_HISTORY.md)。

## 从 API JSON 导入

1. 在 ComfyUI 中准备工作流，使用“导出 API”或“Save (API Format)”保存 JSON。如果界面没有该选项，检查开发者模式设置。
2. 打开 FrameWeave 顶部的“工作流包”，点击“导入工作流包 / API JSON”。
3. 在“定义这个工作流的输入”中填写包名称和用途说明。说明适用任务、所需模型及扩展，方便接收者配置环境。
4. 勾选运行时需要填写的参数，并改成容易理解的名称。每行保留原始节点 ID 和输入名，便于核对绑定。
5. 点击“保存并添加到画布”。之后可在包库点击“添加到画布”重复使用。

普通 ComfyUI 画布 JSON 保存的是界面节点和布局，不能直接作为本功能的 API 工作流。FrameWeave 会提示重新导出 API 格式。FrameWeave 包 JSON 则可直接用同一入口导入。

连接后端有助于识别节点的下拉选项与数值范围；仅导入成功不证明当前后端能够运行。换用后端或更新节点后，应重新执行环境检查。

## 封装当前生成节点

在画布选择已配置的图片、视频或 API 生成节点，打开“工作流包”，点击“封装当前生成节点”。客户端先根据当前配置编译 API 图，再打开输入定义窗口。

这一操作需要当前节点能通过后端编译检查：填写必要提示词、模型和参考图，先解决缺失节点或不兼容参数。封装时不会提交生成任务。

已是工作流包的节点可以直接“导出此工作流包”。包内容与当前画布实例的输入分开保存；在右侧修改本次提示词，不会自动改写包中保存的默认值。

## 选择合适的输入

| 输入 | 建议用途 | 使用方式 |
| --- | --- | --- |
| 文本 | 正向、反向提示词及其他描述 | 右侧多行填写 |
| 整数、数值 | 尺寸、采样步数、种子、引导强度 | 填写数字并遵守范围 |
| 开关 | 节点支持的布尔选项 | 勾选或取消 |
| 下拉选项 | 采样器、调度器或模型选项 | 从包定义的候选值中选择 |
| 图片 | 图生图、首尾帧、参考图 | 使用“选择本地参考图”上传 |

“推荐输入”可快速选择常用参数。“全选”适合需要完整调节的模板。未勾选的参数保留 API 图中的固定值；表单不会改写节点之间的连线。

模型名称通常适合固定在一个经过验证的模板中；若准备在多套本地环境复用，可以开放相应模型输入。接收者仍需使用当前后端实际列出的模型名称，模板下拉列表不会自动下载或重命名模型。

标准图片加载节点的图片参数必须开放，不能取消勾选。保存包时会清空该图片输入，让使用者提供自己的参考图，避免把创建者的后端文件名当成可共享素材。

## 填表生成图片或视频

1. 在包库点击“添加到画布”，选中新增节点。
2. 在右侧“工作流输入”填写本次参数。带星号的项目必须填写。
3. 图片参数点击“选择本地参考图”，上传 PNG、JPG 或 WebP；单张文件不超过 20 MiB。图片进入当前本地推理后端，表单保存其返回的相对名称。
4. 点击节点上的“检查环境”。工作流包会按本次表单值还原为 API 图，检查实际节点和模型输入。
5. 点击“开始生成”，在“生成队列”查看状态、错误和耗时。成功后使用结果节点预览、播放或下载输出。

图片与视频由包内的工作流决定。视频包须包含当前后端支持的编码和保存节点。工作流包可使用右侧表单输入，也可通过画布连接提供文本与图片字段。

切换后端后，原先上传的图片可能不存在于新后端，需要重新上传。表单验证、节点校验和真实生成是不同阶段：通过前两项仍可能遇到显存不足或模型加载失败。

## 导出、分享与恢复

在包库点击“导出包”，或选中包节点后点击“导出此工作流包”。导出文件包含工作流、表单定义、默认值、包名称和用途说明，不打包模型权重、节点插件、Python 脚本实现、推理环境或原始图片与视频。

**保存的默认提示词、模型名称，以及工作流里未开放的固定输入都会随包导出。** 分享前核对这些文字；导出包并非自动匿名化工作流。包不会携带本次生成结果，也不会把当前表单临时填写值自动写回默认值。

接收者导入包后，应连接自己的 ComfyUI，选择可用模型、上传参考图并执行环境检查。包只描述怎样调用已安装节点，不负责安装扩展、下载模型或执行安装脚本。

“导出画布”保存节点位置、关联包标识及实例输入；“导出包”保存单套可复用工作流定义。0.7.0 跨设备恢复优先使用“导出工作流集合”，一次包含两者。原始素材另行保存。

如果恢复画布后显示“本机包库中没有对应工作流包”，点击“导入对应工作流包”，导入原来的包文件。内容相同的包会恢复同一关联；修改包名称、默认值或图结构后可能形成新的包标识，需要重新添加新包节点。仅有画布 JSON 无法还原缺失包的内部工作流。

## 当前范围

- 单个工作流包或 API JSON 最大 2 MiB，包含 1–1000 个 API 节点，最多开放 64 个参数；本地包库最多保存 200 个包。
- 整数必须处于浏览器可精确表示的范围，随机种子最大为 `9007199254740991`。
- 导入和保存执行结构检查；运行前还会按当前后端校验节点、参数、模型枚举与连线。
- 云端 API 节点、缺失的自定义节点及与当前后端不兼容的图不能直接运行。包的生成速度和质量取决于模型、硬件及实际工作流。

环境问题参见 [环境识别与缺失检查](ENVIRONMENT.md)。ComfyUI 操作入口参见 [ComfyUI 官方文档](https://docs.comfy.org/)，H3 和 Krea 模型配置参见 [H3 原生工作流](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)与 [Krea 2 工作流](https://docs.comfy.org/tutorials/image/krea/krea-2)。


## 原生大型工作流（0.11）

0.11.1 进入前会比较当前及已登记引擎的实时节点与前端扩展；选择后记在该画布节点。匹配度只是导入准备情况，不能代替模型、素材和实际生成检查。“更换工作流引擎”可重新选择；旧执行包保持原绑定，需明确应用新配置才改绑。运行绑定工作流时自动连接其已启动引擎；同一执行链绑定多个不同引擎时会要求分别运行。未完成或提交待确认的任务会阻止切换。

参考图和音频记录实际上传引擎。跨引擎时必须重新上传；外层重绑字段也保留素材来源，不按同名文件猜测。旧画布没有来源记录且即将切换引擎时会提示确认目标后重传。视频保存插件的格式专属参数按实时定义校验；换格式后若旧字段不再适用，需要进入内部更新并重新应用。

在工作流包库选择“导入工作流 JSON”，可以直接导入普通 ComfyUI 画布，包含 UTF-8 BOM 的 JSON。原生文档上限 16 MiB；集合上限 24 MiB。原始文件不改写，工作副本及编辑版本保存在本地数据目录。

外层节点点击“进入工作流”，在所选 ComfyUI 后端的原生界面调节模型、控件、分组和旁路模式。“保存内部草稿”只保存编辑状态；“应用参数并返回”使用原生扩展完成转换和校验，生成外层可复用参数表。外层已应用参数与内部草稿分别保存。外层按现有连接传递提示词、图片和结果，并沿用任务去重与执行前校验。

“配置外层参数与输出”可以选择公开模型、编码器、VAE、LoRA、提示词、采样器和尺寸等当前图中实际存在的字段，并修改显示名称。添加编码器等结构变化在内部完成，应用时把新增字段勾选到外层；日常调参直接在外层完成。选项来自当前后端接口，不假定每个主模型都自带编码器，也不会替用户自动添加或猜测匹配关系。

字段按内部节点标识、输入名及类型匹配。重新进入工作流时，能准确对应原生控件的外层改动会回写；不支持回写的扩展控件明确提示，外层覆盖值仍保留。返回应用时比较上次内部基线、当前外层值和新内部值：只有一边改变则采用该边；两边都改成不同值时，必须明确选择保留哪一边。隐藏、删除或改类型的已连接字段需要重绑或解除连接，不会按相似名称偷偷替换。

输出按保存或预览节点的稳定标识选择。可以只运行选中的输出分支及其上游依赖；跨工作流图片连接还会记录输出节点与该分支内的图片序号，避免新增输出后指向另一张图。删除或改变已连接输出时需要明确处理连线。音频、视频结果可选择与展示，当前跨工作流连线传输仍以文本和图片为主。

编辑器只负责调参；提交生成、上传参考素材在外层完成。切换整套工作流请返回外层导入。原生前端的用户设置与自动保存隔离在当前会话，不覆盖原 ComfyUI 文件。前端和插件由已安装的本地 ComfyUI 提供，不随客户端下载或打包。

若所选引擎缺少前端节点，界面显示具体类型并保留原文，暂停应用，避免保存缩水图。可以复制修复说明，核实插件现行版本或兼容替代；此功能不自动安装扩展。后端执行类、输入、模型和枚举仍会在应用及生成前校验。大型工作流仍受 API 执行图最多 1000 个节点、外层最多 64 个公开参数限制；其余参数留在内部编辑。

缺失节点占位仍留在内部图中时，手动替换或删除后可点击“重新检查节点”；撤销修复会重新提示缺失。如果加载时扩展已把未知节点丢弃，则保持阻止应用，需要补齐扩展后从保留原文重新加载。

工作流集合导出包含内部原文及外层参数包，不包含模型、插件、原生引擎、媒体文件。缺少原始媒体时需要重新上传。自定义扩展的额外管理写入默认不开放；编辑器并不保证所有插件专用管理面板兼容。
