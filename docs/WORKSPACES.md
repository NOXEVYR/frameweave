# 画布与独立生成工作台

0.6.0 将左侧导航分成画布、文生图、图生图、视频生成四个空间。切换页面保留当前画布和各页参数草稿，不会提交生成；切换生成引擎时分别保存各模式的参数、模型、LoRA 与参考图，再次切回或刷新后仍可恢复。模型计算仍由已配置的本地 ComfyUI 执行；客户端不捆绑模型或运行时。

## 画布

初次打开以 100% 显示。支持 20%–300% 缩放；使用浏览器原生布局缩放，避免长期复用低分辨率合成层造成字体放大模糊。已有画布保持保存的视角，点击底部百分比可恢复 100%。

- 双击空白或右键打开节点菜单，在点击位置新建提示词、参考素材、图片/视频生成、结果节点。双击输入框或节点不会新建。
- 左键在空白处拖动框选；中键或空格＋左键平移。滚轮以鼠标位置缩放；Shift 追加选择。
- Ctrl+C / Ctrl+V 复制粘贴节点及内部连接；Ctrl+D 快速复制；复制结果节点不会复用旧任务关联。
- 工具栏可对齐左右/顶部/底部/中心及等距分布；“适配所选”只聚焦所选节点。
- F2 重命名；方向键移动 1 px，Shift+方向键移动 20 px；Delete 删除；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
- “专注画布”展开整个画布；再次点击可返回。节点属性默认收起，选中节点会展开，也可用上方“属性 / 队列”切换。

图片和视频可直接拖入空白处创建素材，或拖到素材节点替换；左键按住输出端口拖到指定输入端口建立连接。详见[素材与连接指南](CANVAS_MEDIA.md)。

画布仍支持原有 JSON 导入/导出、工作流包、连线、任务复用和预览。键盘在输入框或独立生成页中操作时，不触发画布删除等快捷键。

0.7.0 支持把整套工作流作为节点组合：文本和图片字段可接来源，多套工作流按依赖执行，并导入/导出包含定义的集合。详见[工作流组合指南](WORKFLOW_PACKAGES.md#在画布组合工作流070)。

## 图片与视频参数

| 页面 | 原生模式 | 主要参数 |
| --- | --- | --- |
| 文生图 | SDXL 兼容 Checkpoint、Krea 2 | 正负向提示词、宽高、种子、步数、CFG、采样器、调度器、模型与 LoRA |
| 图生图 | SDXL | 上传一张 PNG/JPEG/WebP，按指定宽高缩放并编码；额外调节去噪强度 |
| 视频生成 | H3 文生、首尾帧、1–9 张参考图 | 时长、24 fps、画幅、种子、采样器、CFG、视频/音频 Shift、对应模型与 LoRA |

原生图生图页面目前使用 SDXL。其他复杂编辑流程可以继续使用现有 API 工作流包，不应将未适配模式显示成可直接执行。

模型列表来自连接后端的节点定义。可搜索文件名，手动选择已有的 Checkpoint、DiT、文本编码器、图像/视频 VAE 与音频 VAE。客户端模型根目录用于检查，不会自动变成后端已注册的加载器选项；若列表为空，先连接后端并检查模型/节点，再点“刷新模型”。

支持最多 4 个 LoRA。SDXL 可分别设定模型强度和文本强度；H3/Krea 使用模型 LoRA，不使用文本编码器强度，添加前需要明确选择 DiT 主模型。列表采用对应加载器支持的文件，实际架构兼容性仍须由所用底模与 LoRA 保证。文件名推测只能辅助选择，不能证明效果；提交前会按后端实际节点枚举再次校验。旧画布单 LoRA 设置保持兼容，也可以转换为多 LoRA。

“检查依赖”输出缺失说明；“预览执行参数”编译实际工作流，不启动生成。单击“开始生成”后任务进入本机队列，可以切换页面继续工作。结果可保存、放大预览，或显式放入画布；“参数放入画布”创建可编辑节点。离开生成页会暂停其视频和音频预览。

## 提交恢复

独立工作台在发送前保存请求 ID 与参数快照，后端持久去重。通信失败后使用“查询上次提交”，不会自动再生成。

- 查询到已接受任务：关联原任务，不新增任务。
- 查不到持久记录：原请求可能仍在预检，继续保留同一个 ID；需要恢复时只用“继续发送原请求”，保持发送时的参数快照。
- 明确被后端拒绝：提示本次未受理，允许修正参数。
- pending/unknown：保留证据并检查原后端，不换键绕过去重。

本机存储不可写时停止发送；任务已经接受后的存储警告不能视为生成失败。切换引擎后，旧请求需要先恢复原引擎，参考图也需要重新核对所属后端。

画布与独立生成页的草稿仍保存在本机浏览器存储。源码与新版本保留原 FrameWeave 存储标识；更新时关闭旧窗口后再启动新版可继续使用原端口。新版本不自动关闭已有软件窗口或覆盖其编辑状态。


## 0.10：保存、产物和软件设置

- “我的画布 / 保存”把当前节点、连线、视角和引用的工作流定义保存为命名版本。每次保存新增版本，旧版本保留。载入可撤销，不会自动运行。Ctrl+S 打开保存窗口；导出工作流集合可迁移到另一台电脑。
- 自动保存的浏览器草稿仍与当前工作区关联。命名版本保存在服务数据目录的 `canvases/`，清理浏览器缓存不会删除这些版本。模型、参考媒体与结果文件不嵌入画布。
- 顶栏“生成产物”查看本客户端的图片、视频、音频任务。下载保存副本；“文件位置”只显示经登记引擎目录核实存在的文件。未登记或临时结果仍可通过下载保存。
- 软件设置提供快捷键说明和显存预算。自动档读取当前引擎可用显存，手动档提供预算；生成页点击“按 GPU 建议填充”才会修改尺寸。建议不保证大模型一定可运行，不会改变精度或安装加速插件。

## 编码器与二次重绘

SDXL 页可覆盖 CLIP-L + CLIP-G（必须成对选择）和 VAE，候选来自后端实际加载器。空选择保留 Checkpoint 自带组件。第二阶段支持潜空间放大和独立采样步数、尺寸、重绘强度；实际图及参数随任务冻结保存。缺少节点或不兼容类型时明确禁用，不在其他架构上假装支持同一套设置。

DiT 类模型继续按各自架构选择单独的编码器与 VAE。未内置架构可导入完整 API 工作流，在包中开放相关模型、编码器和采样字段。

## 声音与音乐

左栏“声音 / 音乐”提供两个独立草稿区。导入 ComfyUI API 音频工作流，开放文本、种子、时长、参考音频等输入；软件依据当前后端节点和 AUDIO 输出链显示可用性。用途由使用者选择，不通过文件名猜测模型一定会配音或作曲。

参考音频支持 WAV、FLAC、MP3、OGG（最大 20 MiB）；提交、请求恢复、任务状态和播放下载复用现有任务系统。切换页面或关闭预览暂停播放。没有已安装模型和有效音频工作流时，界面提供导入及检查入口，不自动下载。语音克隆、音色和音乐细节取决于选定工作流实际开放的功能。

## 实时环境证据

当前配置的生成引擎与自动发现的其他引擎分别列出；没有启动的备用探测端口折叠展示，不算缺失。连接拒绝、响应超时和非 ComfyUI 服务各有说明。诊断从实时 object_info 读取节点输入、输出与可选值，修复提示包含脱敏后的版本和具体失败项。潜在替代节点只列通过整图接口检查的候选，语义与生成质量仍需验证，不自动换插件。


## 历史参数与能力刷新

图片、图生图和视频工作台的结果区区分「加载参数到本工作台」与「复制参数到画布」。加载只填入可编辑草稿，不提交生成；原草稿通过「恢复加载前草稿」恢复，浏览器重载后仍保留。请求读取期间禁止生成，切换页面、引擎、任务或修改目标草稿会使迟到响应失效。API/工作流包任务通过画布编辑完整参数，不伪装成预设模型表单。

恢复使用原请求的尺寸、种子、模型、编码器、LoRA 和顺序参考图。旧版只记录开启二次重绘时，仅用同一任务保存的已解析摘要补齐缺省参数；没有可靠记录则要求查看完整画布工作流。参考预览只能来自原后端已登记素材或同归属的现有草稿；缺少预览会说明，运行前仍需检查原文件是否存在。

SDXL 外置编码器与高清二次重绘控件随实时能力局部更新，保持草稿、数值输入和折叠状态。失效的旧选择会明确标注，可主动清除编码器覆盖或关闭二次重绘；刷新模型不会代换算法。标准工作流包导入在离图阶段准备输入输出，再一次加入画布；一次撤销移除完整新节点，重做恢复，包库中的已导入文件保持可用。
