# 棱光 PrismCanvas 0.11.5 Phase8A 候选

复杂工作流可作为画布节点导入，自动识别常用输入，手动选择要暴露的参数，并进入原生 ComfyUI 编辑后同步回外层。本轮修复已登记素材在引擎端失效时无法主动恢复，以及标准共享音频自动提升预览阻止部分实例同步的问题。

“同步参考素材到引擎”可重新上传保留在客户端的直连图片、视频或音频。同一素材连接多个端口时先统一验证，再上传一份。音频共享实例分别使用各自输入；切换时停止旧播放器，保存保留原默认值和预览配置。修改预览配置时尊重用户操作，临时暂停不会写成工作流默认值。

- [Windows x64 候选包](PrismCanvas-0.11.5-Phase8A-Windows-x64-candidate.zip)：约 10.59 MiB。
- [固定源码包](PrismCanvas-Phase8A-Source.zip)：约 1.47 MiB。
- [精确大小与 SHA-256](release-manifest-v0.11.5-Phase8A-candidate.json)。

最终前端 1589 项通过；后端 1197 项通过、3 项 Windows 符号链接权限跳过。实际 Windows EXE 完成图片恢复 22、视频恢复 25、共享音频恢复 25、两段不同音频 24 项页面断言，预览阶段零生成。另完成 5 项 CPU 执行检查：一次任务、两份图像按输出节点逐像素匹配。39 个内嵌 Python 模块和 67 个页面文件匹配封存源码，ZIP 校验、解压后两次启动与旧工作区副本兼容均通过。

这是公开复核候选，主分支与稳定更新源未提升，旧候选保留。包内没有模型、ComfyUI、扩展或用户数据。自动提升音频当前支持已证明的单层标准 LoadAudio，关联宿主至多一项对应的 audioUI；复杂多层、自定义播放器或未知前端模块结构继续保留原值并报告能力不足。此次没有新的 GPU 模型推理、神经语音质量或人工音频审听验收，TTS 与 H3 运动还原质量仍在推进。

源码包保留构建前的封存记录；上述成品验收是后续完成的当前交付证据。操作说明见[工作流接口](../docs/WORKFLOW_INTERFACE.md)，开发历史见[验证记录](../docs/VALIDATION.md)。
