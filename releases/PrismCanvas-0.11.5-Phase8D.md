# 棱光 PrismCanvas 0.11.5 Phase8D 候选

声音环境现在可以在棱光设置中登记已有 ComfyUI、语音 Python、独立依赖和 Qwen3-TTS VoiceDesign 权重。登记创建独立运行目录和可复用 AUDIO 工作流包；用户明确启动、连接后，直接在声音工作台填写台词和声音描述，进入原生 ComfyUI 调参，再同步返回外层。输出可播放、下载、定位及放入画布，参数可复制为继续编辑的工作流节点。

- [Windows x64 候选包](PrismCanvas-0.11.5-Phase8D-Windows-x64-candidate.zip)：10.65 MiB。
- [固定源码包](PrismCanvas-Phase8D-Source.zip)：1.56 MiB。
- [精确大小与 SHA-256](release-manifest-v0.11.5-Phase8D-candidate.json)。

一次配置后可复用，重新检查会填回路径。文件检查不启动模型，也不代表 GPU 推理已通过。命名声音引擎核验服务及环境 ID；生成前再次检查，防止端口被其他 ComfyUI 占用。模型与依赖均引用既有文件，主 ComfyUI 不安装本适配插件。CPU 宿主与独立 CUDA 工作进程分开；取消、超时只结束本任务工作进程，不自动重提。

Python 全量 1286 通过、3 跳过，Node 1671 通过；最后的损坏分片索引校验修订另通过 55 项声音定向回归。源码隔离流程 34 项、实际 Windows EXE 33 项界面/编辑/画布/取消检查通过，各有一次成功的 3.36 秒、24 kHz 单声道神经语音和一次主动取消。浏览器音频解码与播放通过，固定短句两次结果相同；不能据此保证任意文本、音质或推理速度。人工试听仍未验收。

最终 ZIP 的 CRC、成员摘要和解压程序两次启停通过。源码 ZIP 与包内清单是构建时检查点，之后的交付记录只追加在仓库文档中。候选沿用独立版本目录及原桌面入口；旧版、原参数和工作区保留。本机替换记录见[验证记录](../docs/VALIDATION.md)，公开包可按上面的精确大小与 SHA-256 校验。

使用：软件设置 → 声音运行环境 → 填写已有路径 → 检查 → 登记 → 我的引擎启动并连接 → 声音/音乐选择工作流包。目前此适配器支持 CUDA 0、bfloat16、SDPA 和 VoiceDesign 中文/英文短句；Base/CustomVoice、其他硬件和音乐模型需各自适配验证。环境变更建立新副本并保留原件，旧副本自动回收尚未提供。
