两层共享子图中的标准音频预览现在能沿已验证的祖先与别名链隔离。同一物理音频叶节点的多个命名别名可以共用隔离；切换显示时旧播放器停止并卸载，返回后可重新预览。内部保存与导出仍保留原来的六个备用输入和预览表，外层连接不会污染默认值。返回画布期间保留“正在返回”状态，关闭完成后再允许重入。

源码真实界面完成六路图片、视频、音频连接、字节核对、尺寸与时长解码、播放停止、干净导出、保存重入和执行 JSON 身份核对，共 68 项；连续重入 10 项。另验证原生同所有者重建两次后 API 的参数与连线保持一致。实际 EXE 共 87 项界面检查通过，76 个内嵌网页摘要一致，解压包另一次冷启与退出成功。全量 Node 1797 项：1796 通过、1 项既有 VHS 环境跳过；Python 未改动，本阶段未重跑全量 Python。

本阶段没有 GPU 模型生成画质、全部大型工作流分支、全部插件版本或人工音频验收。混合多个不同媒体叶节点的同一预览表、指定实例的独立预览覆盖仍需明确适配，无法证明归属时保持原文并报明原因。客户端包不含模型、ComfyUI、插件或用户数据；连接已有本地 ComfyUI 使用。
